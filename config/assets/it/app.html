Installieren

Wenn Sie den nachfolgenden Schalter klicken, bieten die meisten Browser das Ausführen der Datei 'setup.exe' an. Wenn Ihr Browser nur das Herunterladen der 'setup.exe' anbietet, speichern Sie diese Datei auf Ihrem PC und starten Sie sie danach. Sie benötigen dazu keine Administratorrechte.
